# BTech e-Shop — Early HTML Practice Project

An early HTML practice project: a mock electronics e-shop called **BTech-e-Shop**, built while learning the basics of HTML and CSS. It walks through a simple flow — a logo splash page, sign-up and login forms, and a long product page listing laptops, TVs, phones and other categories with images and links. It is kept here as a record of learning, not as a working store.

## Features

- Logo splash page that links into the sign-up form
- Sign-up form (email, username, password, gender, age) and a separate login form, using fieldsets, labels and HTML validation attributes
- Product catalogue page with category sections: laptops, televisions, refrigerators, washing machines, mobiles, accessories, smart watches, audio, sports and more
- In-page anchor navigation between categories
- An earlier draft page (`trywebpage.html`) with an introduction section
- Basic JavaScript `alert` prompts on the splash and sign-up pages

## Tech stack

- HTML5
- CSS (inline styles)
- A little JavaScript

## How to run

**Live demo:** https://amithviswas.github.io/html-webpage/

Or run it locally:

```bash
git clone https://github.com/amithviswas/html-webpage.git
cd html-webpage
```

Then open `index.html` in any modern browser. No build step or install is needed.

### Page flow

`logo.html` → `index.html` (sign up) / `form2.html` (login) → `ourwebpage.html` (products)

## Project structure

```
html-webpage/
├── index.html             # Sign-up form (entry page)
├── form2.html             # Login form
├── logo.html              # Logo splash page
├── ourwebpage.html        # Main product catalogue page
├── trywebpage.html        # Earlier draft of the product page
└── btech-e-shop-logo.png  # Shop logo
```
